# API de referencias de mercado para Padawanway

La documentación compartible de esta integración se mantiene en [api-doc/README.md](../../api-doc/README.md).

La integración está operativa en producción. Ese paquete incluye:

- contrato de requests, responses y errores;
- autenticación HMAC y vector de prueba;
- colección reproducible en Postman;
- guía para el frontend de Padawanway;
- checklist de operación, pruebas de cambio y rotación de credenciales.

El cambio técnico procesado y los criterios de aceptación internos permanecen en [2026-07-17-referencias-mercado-api.md](../changes/processed/2026-07-17-referencias-mercado-api.md).
