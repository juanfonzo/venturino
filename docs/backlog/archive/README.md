# Archive

Archivo compacto de features completadas.

Crear un archivo por mes:

- `2026-05.md`
- `2026-06.md`

Cada entrada debe conservar trazabilidad suficiente para que el archivo individual pueda moverse o borrarse.

Formato:

```md
## YYYY-MM-DD - Feature

Origen:
Hito:
Resumen:
Commits/PR:
Validación:
Decisiones:
Riesgos residuales:
```
