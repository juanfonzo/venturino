# Roadmap

## Hitos

| Hito | Estado | Objetivo de negocio | Criterio de salida |
|---|---|---|---|
| Hito 1 - Fundación | completado | Base estable del sistema | App Next.js, PostgreSQL/Prisma, autenticación interna y pipelines disponibles. |
| Hito 2 - Postventa | implementado parcial | Comparar postventa Venturino contra MercadoLibre | Ingesta, análisis, UI y PDF implementados; MCP queda como contrato-candidato. |

Estados: `pendiente`, `en-proceso`, `completado`, `pausado`.

## Orden De Entrega

1. Fundación técnica y datos críticos.
2. Primer flujo operativo completo.
3. Módulos complementarios.
4. Automatizaciones, MCP y reportes.
5. Hardening y entrega.
