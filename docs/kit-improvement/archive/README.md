# Archivo De Señales Del Kit

Usar archivos mensuales `YYYY-MM.md` para compactar señales cerradas.

Mover aquí señales con estado:

- `promovida`
- `descartada`
- `fusionada`

Conservar:

- fingerprint;
- decisión;
- motivo;
- cantidad de ocurrencias;
- archivos modificados si hubo cambio;
- enlace o referencia a backlog interno si aplica.
