# Kit Improvement

Sistema liviano para capturar señales de mejora del kit sin convertir cada observación en una regla nueva.

## Uso

- Los agentes ejecutores registran señales mínimas en `inbox.md`.
- No diseñan la solución del kit salvo que sea evidente y pequeña.
- El agente `refinamiento-kit` revisa señales a demanda.
- Las señales promovidas, descartadas o fusionadas se compactan en `archive/YYYY-MM.md`.

## Relación Con Otros Artefactos

- `inbox.md`: señales crudas activas.
- `archive/`: trazabilidad compacta de señales cerradas.
- `docs/ai/LESSONS.md`: aprendizajes activos o promovidos que cambian comportamiento.
- `docs/backlog-interno/mejoras.md`: mejoras del kit que requieren trabajo posterior.

## Regla

No modificar el kit sin evidencia o repetición, salvo riesgo alto o crítico.
