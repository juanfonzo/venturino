# Pending Changes

Colocar aqui solo solicitudes reales del cliente durante mantenimiento.

No guardar plantillas vacias en esta carpeta. Usar `../TEMPLATE.md`, copiarlo con nombre especifico y completar el pedido antes de pedir procesamiento.

Cada archivo real debe indicar:

- fecha
- origen
- pedido
- contexto
- urgencia
- preguntas abiertas

Despues de procesar, mover el archivo o crear resumen en `../processed/` o `../rejected/` segun corresponda.
