# Backlog Interno

Backlog para mejoras internas del sistema y del proceso de trabajo.

Usar para:

- deuda técnica
- refactors necesarios
- automatización pendiente
- mejoras de observabilidad
- mejoras de DX
- optimización de performance
- mejoras del propio flujo de agentes/documentación

No mezclar con features pedidas por el cliente. Las features de cliente van en `docs/backlog/` o `docs/changes/`.
