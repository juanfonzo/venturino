# Guía Del Desarrollador

Estado: compactada

## Guía Principal

La guía operativa vigente para usar el kit con Codex es:

- `GUIA_USO_CODEX_KIT.md`

Ese archivo concentra el uso diario recomendado:

- inicio robusto de proyectos;
- refinamiento de faltantes;
- backlog técnico;
- features pesadas y livianas;
- bugs y regresiones;
- CodeGraph opcional para repos grandes;
- MCP-first en Python/FastAPI;
- testing proporcional;
- UTF-8;
- mejora continua;
- prompts recomendados.

## Motivo De Compactación

Esta guía se mantiene como punto de entrada compatible para quienes busquen el nombre anterior.

Para evitar duplicación, deriva a la guía nueva y a las políticas canónicas del kit.

## Regla Corta

El desarrollador conversa con Codex. Codex administra el kit, revisa contexto antes de editar, implementa sólo lo necesario, verifica proporcionalmente y cierra limpiando backlog, cambios, manifest y coverage MCP cuando corresponde.
